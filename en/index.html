THE NOVA VERSE PATH

Four stages. One clear journey.

Each stage builds on the one before it, moving students from exploring technology to building projects and using future-facing tools.

01
EXPLORER12 Sessions

Explorer

Foundations • Scratch • PictoBlox

Explore computers, computational thinking, algorithms and visual programming through hands-on creation.

Understands how programs think and starts creating first projects.
02
BUILDER12 Sessions

Builder

Python Programming

Move from blocks to real Python code and build a small application using core programming concepts.

Moves from arranging blocks to confidently writing code.
03
CREATOR12 Sessions

Creator

HTML • CSS • VS Code • JS Basics

Build a first web experience, use developer tools and turn a visual idea into a working page.

Leaves with a website they can open, present and improve.
04
INNOVATOR12 Sessions

Innovator

AI • Prompting • Responsible Use

Understand AI, explore practical tools, write stronger prompts and develop critical, responsible habits.

Uses AI as a tool for creation—not as a replacement for thinking.
